# Seções Cônicas e Cortes de Quádricas

Modelos 3D didáticos para visualização e estudo das **seções cônicas** e dos **cortes ortogonais de superfícies quádricas**.

O projeto apresenta as seções do **cone de Apolônio** e diferentes cortes realizados nas seguintes quádricas:

- **Paraboloide hiperbólico**
- **Elipsoide**
- **Paraboloide elíptico**
- **Hiperboloide de uma folha**
- **Hiperboloide de duas folhas**

Os modelos foram projetados para facilitar a compreensão da geometria espacial e da relação entre as superfícies quádricas e suas respectivas curvas de interseção.

Todas as peças possuem **ímãs aparentes**, permitindo uma montagem e desmontagem rápida e facilitando a visualização das diferentes partes dos modelos.

## Arquivos disponíveis

- `.stl` — Modelos 3D prontos para impressão.
- `.3mf` — Arquivos fatiados e configurados para impressão no **Bambu Studio**.
- `.jpg` — Fotos das peças após a impressão.
- `.jpeg` — Fotos dos modelos montados após a fabricação.

## Objetivo

O projeto foi desenvolvido como um recurso **didático e visual para o ensino de Geometria Analítica e Geometria Espacial**, permitindo explorar fisicamente conceitos que normalmente são apresentados apenas por meio de representações bidimensionais.
